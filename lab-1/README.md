## Ход работы
### Теоретическое описание метода
Медианный фильтр заменяет значение пикселя медианой значений в локальном окне. Для окна размера `k x k` в него входит `k^2` значений, а результатом становится элемент с индексом `k^2 // 2` после сортировки.
Фильтр хорошо удаляет импульсный шум и сохраняет резкие границы лучше, чем линейное усреднение. При увеличении размера ядра шум подавляется сильнее, но мелкие детали изображения могут исчезать.
В работе размер ядра задаётся при запуске. Допустимы нечётные значения `3`, `5`, `7` и больше. Для обработки границ используется репликация крайних пикселей (`BORDER_REPLICATE`), что позволяет сохранить размер изображения.
### Описание разработанной системы
[Ссылка на Github-репозиторий](https://github.com/WayDansten/computer-image-processing-systems/tree/main/lab-1).
Организация файлов и кода:
- `median_filter.py` содержит общий контракт и две реализации:
	- `median_filter_library` использует `cv2.medianBlur`;
	- `median_filter_native` обрабатывает окно циклами Python, сортирует его значения и выбирает медиану.
- `benchmark.py` генерирует `.csv` файлы с результатами сравнения native и library методов.
- `main.py` предоставляет CLI для обработки, сравнения и измерения времени.
- `tests/` содержит тесты параметров, форматов изображений и совпадения результатов.
